# NexExam Marketing Site

This folder contains the exported Webflow marketing site for NexExam.

Deployment target:

- `nexexam.com` serves this static export on Render.
- `app.nexexam.com` serves the SaaS app.
- `api.nexexam.com` serves the backend API.

When the Webflow design changes, export the site again and replace the static
files in this folder, then re-apply the NexExam cleanup pass for links, SEO, and
contact handling.
